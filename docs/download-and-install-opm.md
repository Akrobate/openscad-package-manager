# 📥 Download and Installation

## Linux (ubuntu)

- [download](https://github.com/Akrobate/openscad-package-manager/releases/download/0.0.2/opm_0.0.2_linux_amd64.tar.gz`)
- extract the tar archive
- move opm to /usr/local/bin/

### Commands

```shell
curl -L -O https://github.com/Akrobate/openscad-package-manager/releases/download/0.0.2/opm_0.0.2_linux_amd64.tar.gz
tar xvf opm_0.0.2_linux_amd64.tar.gz
sudo mv opm /usr/local/bin/
```
